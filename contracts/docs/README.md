# Wallet Guardian

> A minimal smart wallet that executes a predefined rule automatically —
> no manual monitoring, no missed triggers.

---

## The Problem

Crypto wallets are passive. If you want to protect funds when a price
drops, or move assets when a target is hit, you have to watch markets
manually and act in time. Most people don't. They lose.

---

## The Solution

Wallet Guardian lets you set one rule — once — and the contract
executes it automatically when the condition is met.

**Set it. Forget it. It fires.**
